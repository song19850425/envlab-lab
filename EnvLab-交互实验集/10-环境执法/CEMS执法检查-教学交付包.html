01 · 学生实操手册
把现场检查的一天，拆成可照做的操作卡
以下三块对应交互页四关的底层逻辑：先按标准链路走程序，再背熟判据速查表，最后对照易错清单自查。所有数值与判定口径与交互页一致，不得改动。
1.1 现场检查六步操作卡
现场检查（CEMS）标准链路，顺序错了，证据可能不被采信。每张卡写：步骤名 ＋ 做什么 ＋ 这一步最容易错在哪。
STEP 1进站房前固定现场原始状态做什么：拍照录像、记录仪表参数与各阀门开度，先把现场原始状态固定下来。最容易错：一进门就动设备，原始状态灭失，物证不可逆。
STEP 2站房勘察与异常识别做什么：识别旁路管、三通阀、标气瓶与标签、伴热温度、探头状态等异常。最容易错：只看仪表读数，漏看管路与阀门的物理伪装——多出的三通阀是造假直接物证。
STEP 3先取证，后动手做什么：先固定物理痕迹（拍照 / 录像 / 备份日志）再拆阀复位。最容易错：先拆旁路阀再拍照，现场原始状态灭失，证据不可逆。
STEP 4拆除伪装与采样管线复位做什么：按正确顺序关闭旁路阀、拆除伪装三通阀、恢复采样管线直连。最容易错：顺序错（未先取证就拆）→ 证据可能不被采信。
STEP 5分析仪参数与备案 / 验收值一致性核对做什么：核对斜率、截距、量程、输出下限与备案 / 验收值。最容易错：只核仪表参数、不调后台日志与 DAS 操作记录，数据链条对不上。
STEP 6标准气体盲测做什么：执法方自带标气，从采样探头处通入，检验含采样管线的全系统。最容易错：用企业自测结果当执法结论；盲测不用自带标气、或错用分析仪口径判系统响应。
1.2 判据速查表（已核准口径，原样不得改动）
下列判据为已核准口径，必须原样使用，不得改动数值。现场检测判定以"系统（含采样管线）"口径为准，实验室 / 型式检验口径仅作对照、现场不引用。
技术指标判据与出处（原样，不得改动）
示值误差SO₂ 满量程 ≥100 μmol/mol（NOx 满量程 ≥200 μmol/mol）时 ≤ ±5%（相对标准气体标称值）；量程低于该档时 ≤ ±2.5%（相对满量程 FS）。（HJ 76-2017 §6.2.1.1，两档）
系统响应时间≤ 200 s，含采样管线的现场系统口径。（§6.2.1.2）
分析仪仪表响应时间≤ 120 s，属实验室 / 型式检验口径，现场检测不引用（两档禁混用）。（§6.1.1.1）
零点 / 量程漂移（24 h）分析仪（§6.1.1.4，24 h）≤ ±2% FS；气态污染物 CEMS ≤ ±2.5% FS；颗粒物 CEMS ≤ ±2% FS。
伴热要求两条件并列 —— 温度 ≥ 120 ℃，且 高于烟气露点 10 ℃ 以上。（HJ 75-2017 §7.2.7）
校准与校验校准（§11.2，四档：24 h / 15 d / 7 d / 3 个月）与校验（§11.3）不得混用。
数据传输标准HJ 212-2025 全部代替 HJ 212-2017，2026-01-01 实施。
1.3 常见错误与排查
现象根本原因怎么查
先拆旁路阀再拍照现场原始状态灭失，物证不可逆进场先固定原始状态（拍照 / 录像 / 备份日志），再动手拆阀 / 复位
用分析仪 ≤120 s 去判现场系统响应口径混用：分析仪 ≤120 s 是实验室 / 型式检验口径，现场应判系统（含采样管线）≤200 s现场系统响应时间按 §6.2.1.2 ≤200 s 判定，不得套用 §6.1.1.1
示值误差用满量程 FS 作基准量程达档时应相对标准气体标称值，而非 FS量程 ≥100 μmol/mol（SO₂）时，示值误差以标气标称值为基准、≤ ±5%
把"校验"当"校准"§11.2 校准与 §11.3 校验是两件事，周期与目的不同区分校准（24 h / 15 d / 7 d / 3 个月）与校验，各按其条款执行
伴热只查 ≥120 ℃、漏掉"高于露点 10 ℃ 以上"两条件是并列关系，缺一不可同时核验温度 ≥120 ℃ 且 高于烟气露点 10 ℃ 以上（HJ 75-2017 §7.2.7）
标气瓶过期或无证仍出具合格结论标准物质须可溯源，过期 / 无证即不可信查标气证书有效期与溯源编号，无证 / 过期不得作为合格依据
只改台账不改后台日志数据链条对不上，篡改痕迹仍在 DAS / 仪表日志台账、DAS 与仪表操作日志交叉核对，参数修改记录须一致
把企业自测结果当执法结论须用执法方自带标气盲测，企业自测可能预先应对执法方自带标准气体从采样探头通入做全系统盲测

作业 1 ·《这条链路上哪几处能动手脚？》
题目背景（脱敏设定）：某钢铁企业排口安装 CEMS，采样链路为：采样探头 → 伴热管线 → 预处理 → 分析仪 → 数据采集传输仪（DAS）。请逐环节分析这条链路上可能被动手脚的位置。
任务清单：
  1. 沿采样链路逐环节写出可能的造假手法（至少覆盖探头 / 伴热 / 预处理 / 分析仪 / DAS 五处）。
  2. 为每一条手法给出现场可见特征（即在站房现场能被直接观察到的破绽）。
  3. 用一句话概括四类典型手法（旁路稀释 / 标气作弊 / 参数篡改 / 采样失真）分别发生在哪段。
评分项分值评分要点
逐环节列出造假手法（5 环节）50探头 / 伴热 / 预处理 / 分析仪 / DAS 各环节至少给出一种手法，缺一项扣 10 分
给出现场可见特征40每条手法对应可现场识别的特征（多出阀门、标签撕毁、伴热不足、日志异常等）
表述规范10引用"旁路稀释 / 标气作弊 / 参数篡改 / 采样失真"等关键词，逻辑清晰

作业 2 ·《这三份验收数据，哪份过得了？》
题目背景（脱敏设定）：SO₂ 标准气体标称值 200 μmol/mol、分析仪量程 500 μmol/mol。现场给出三组验收数据，请按 HJ 76-2017 判定哪组符合、哪组不符合。
编号示值误差系统响应时间24 h 漂移
①+3.8%165 s−1.8% FS
②+6.2%240 s−3.1% FS
③+2.0%用的是分析仪 110 s用 ±2% FS 判据
任务清单：
  1. 写出判定所用判据：示值误差（量程 500 ≥100，按 ±5% 相对标气标称值）、系统响应时间（≤200 s，含采样管线）、气态污染物 CEMS 24 h 漂移（≤±2.5% FS）。
  2. 对三组数据逐项写出判据与结论。

作业 3 ·《现场检查笔录怎么写？》
题目背景（脱敏设定）：执法人员突击某站房，发现三处异常：① 采样管线旁多出旁路三通阀；② 分析仪斜率被改为 0.78（备案 1.000）；③ 标气瓶已过期、证书缺失。请按"先取证、后动手"顺序拟写检查步骤。
任务清单：
  1. 按"先取证、后动手"顺序写出检查步骤（先固定什么、再做什么）。
  2. 列出应当固定的证据类别（物证 / 文书 / 数据 / 比对）。
  3. 说明顺序错（先拆阀再拍照）会导致什么后果。
评分项分值评分要点
检查步骤符合"先取证、后动手"50先拍照 / 录像 / 备份日志固定物证，再拆阀复位；顺序错（先拆后拍）即扣分
证据类别完整40物证（照片 / 录像 / 旁路阀 / 过期标气）、文书（笔录 / 询问）、数据（参数记录 / DAS 日志）、比对（盲测记录）
