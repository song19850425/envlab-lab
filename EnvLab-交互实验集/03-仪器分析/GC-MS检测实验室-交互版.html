红线一 · 衬管与分流
高浓度样不分流 = 离子源污染，拆洗离子源半天没了。衬管脏了 → 峰拖尾、鬼峰，先换衬管再怀疑人生。
红线二 · 程序升温
升温太快 → 分离度打折、保留时间前移，定性用的保留时间窗口得重建；太慢 → 峰展宽、峰变矮，灵敏度掉还耗时。DB-624 上限 260℃，超温就是柱流失。
红线三 · 调谐与真空
PFTBA 调谐（69/219/502）不过，后面定的性全是猜的。分子泵高真空约 10⁻⁴ Pa，真空不良直接烧灯丝。
▸ 模型与公式（确定性演示，无随机数凑结果）
内标法：Cx = (Ax / Ais) × Cis / RF RF=1（演示） tR(苯) = 2.0 + 25.6/R tR(甲苯) = 2.6 + 41.6/R R = 升温速率(℃/min) Rs = ΔtR / w w = 0.28×(8/R)^0.25（峰宽） S/N = A / N A = C×f分流×f模式×500，N = 1000 判定：S/N≥3 检出，≥10 定量；A > 5×10⁵ 过载（削顶） SIM 灵敏度约为 SCAN 的 60 倍（盯特征离子） 实际方法检出限见 HJ 759-2015 附录A（SCAN、100mL：约 0.3~5.4 μg/m³）
