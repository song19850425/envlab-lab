### 叙事主线（四拍）

1. **钩子**（0–4s）——点破痛点：照着步骤点一遍，算不算学会？
2. **证明**（4–46s）——三个真实判错瞬间：跳过被拦、改参数作废、异常给物理解释
3. **规模**（46–54s）——88 个页面 / 单文件 / 离线可用
4. **行动**（54–60s）——给出网址

**关键取舍**：60 秒只讲一件事——「判错机制」。不要试图在片子里展示采样、仪器、评价全貌，那样每个点都只有 3 秒，观众记不住。

## 三、录屏设置

### 录屏前（关键，决定成片清晰度）

1. 用 **Edge** 打开 `竖版60秒-自动演示页.html`（中文配音音质明显好于 Chrome）
2. 按 **F11** 全屏，或把浏览器窗口拖成竖长条（宽高比接近 9:16）
3. 演示页会自动等比缩放到窗口内并居中，**黑边是刻意的**，后期裁掉即可
4. 页面会先出现一个开始闸门——浏览器必须有一次点击才允许播放语音。**先点「开始播放（含配音）」，再开始录屏**
5. 按 **空格** 可暂停/继续，**← →** 跳上一镜/下一镜，**R** 从头重播，**V** 开关配音
6. 演示页播完 60 秒自动停止，停止后按 R 重录

### 录屏参数

| 项目 | 建议 |
|---|---|
| 录制工具 | OBS（推荐）或系统自带录屏；OBS 设「窗口采集」+ 1080×1920 输出 |
| 分辨率 | 1920×1080 屏幕 → 录完裁切出中间 9:16 区域；或直接 OBS 设竖版画布 |
| 帧率 | 30 fps（若平台支持 60 fps 更顺滑） |
| **音频** | **OBS 添加「桌面音频」采集**，否则录不到配音；音量表要能看到跳动 |
| 光标 | **务必隐藏鼠标指针**（OBS 里关掉「捕获光标」），否则会破坏自动播放的观感 |
| 单镜重录 | 用 `?scene=N` 直接跳到第 N 镜（N 从 0 开始），例如 `...html?scene=1` 只录镜 2 |
| 截封面帧 | 用 `?scene=N&auto=0&t=<毫秒>` 定格在指定画面（见第四节参数表） |

### 后期

- 用剪映/PR 裁到 9:16，去掉黑边
- 保留演示页自带的顶部进度条（它本身就是视觉节奏）
- **不要加转场特效**——六场之间用硬切更利落，与站点的克制调性一致

## 四、配音（已内置在演示页里）

演示页已接入**浏览器中文语音合成**：点「开始播放（含配音）」后，旁白会按分镜时间码自动念出来，音画天然对齐，不需要单独的音轨文件。

### 为什么是浏览器语音合成

本产品不能生成音频文件（不支持音频/视频生成），所以改用浏览器内置 TTS。反而有个好处：**旁白和画面共用同一个时钟，永远不会不同步**，省掉了音画对轨这一步。录制时用 OBS 的「桌面音频」把声音一起录进去即可。

### 音质提示（重要）

**用 Edge 打开，音质明显更好。** Edge 内置微软神经网络中文语音（Xiaoxiao / Yunxi 等 Natural 音色），接近真人；Chrome 只能用系统本地语音（如 Microsoft Huihui），机械感较强。演示页会**自动优先挑 Natural 音色**，挑不到才退回本地语音。

两点说明：

- 数字刻意写成中文（十八 / 二十六 / 八十八），避免合成引擎把阿拉伯数字读错。

### 想换成真人配音 / 剪映配音

按第二节分镜表的「旁白 / 配音稿」那一列录，时长足够。录完在剪辑软件里对齐时间码即可；演示页按 **V** 关掉内置配音，只留画面。

### 音轨混音

| 音轨 | 建议 |
|---|---|
| 旁白 | 主音轨，-6dB 左右 |
| 背景音乐 | 极简电子/氛围，无鼓点或少鼓点，压到 -22dB，**不能盖过旁白** |
| 音效 | 镜 2「被拦」处一记短促低沉的「咚」（0.3s），镜 3「作废」处一声「唰」。**全片音效不超过 3 处** |

### 配音相关快捷键

| 键 | 作用 |
|---|---|
| **V** | 开关配音（关闭会立即中断当前语音） |
| 空格 | 暂停 / 继续（语音同步暂停与恢复） |
| ← → | 跳到上一镜 / 下一镜（自动中断当前语音） |
| R | 从头重播 |

### 地址栏参数

| 参数 | 作用 |
|---|---|
| `?auto=1` | 跳过开始闸门，直接静音播放（浏览器未获交互时无法出声） |
| `?auto=0` | 定格模式：停在指定时间点不播放，用于截封面帧，配合 `?t=` 使用 |
| `?scene=N` | 从第 N 镜开始播（N 从 0 开始），用于单镜重录 |
| `?t=<毫秒>` | 定位到指定时间点，如 `?t=34000` 是镜 4 开头 |

封面帧推荐：`?scene=1&auto=0&t=7300`（STEP 3 被拦住的瞬间）。
