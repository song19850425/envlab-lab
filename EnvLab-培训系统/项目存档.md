# EnvLab 仪器操作培训系统 · 项目存档

> 归档日期：2026-07-20 ｜ 状态：**阶段性收尾**（云端共享静态版已上线，移动端适配完成）
> 一句话：把"真实受控操作规程的致命红线"做成可交互、带记录、手机可学、点开即用的上岗培训系统。

## 1. 产品定位与商业逻辑
- **B 包装（上岗培训订阅）MVP**：按仪器定制 + 带记录可查。新人上岗前在屏幕上把顺序和红线走熟，培训记录可当 CMA/CNAS「人员能力确认」佐证（加分项，非拿证门槛）。
- **A 包装（按客户操作规程定制）落地方式**：把客户操作规程改写成 `instruments/*.json` 丢进系统，零改代码即新增一台仪器培训。
- **价值来源**：不在「网页交互」本身，而在内容（真实红线 + 合规痕迹）——解决「纸质规程没人看、培训无留痕」的痛点。

## 4. 技术架构
- **配置驱动**：每台仪器一个 JSON（`op` 5 节规程+红线 / `steps` 5 题含 fatal 致命项 / `opPage` 指向交互页）。加仪器只加 JSON，不改引擎代码。
- **状态机红线拦截**：选项 `correct` / `wrong` / `fatal`，fatal 命中记 0 分并标红阻断，确保「致命顺序错了不放行」。
- **双模存储**：`api.js` 的 `Cloud` 对象云端优先，fetch 失败自动回退 localStorage（回退模式）。
- **学习阶段前置**：选仪器 → iframe 嵌入已做好的完整操作规程交互页（先学后答）→ 答题时随时「查看要点」。
- **管理员闸门**：`admin.html` 仅 `name=ENVLAB && emp=001` 放行，读本机记录 + 筛选 + 导出 CSV。
- **可选后端**：`server/index.js`（Node 内置模块零依赖，JSON 文件库 `db.json`，Bearer Token 鉴权，拦截 `/server/` 与 `/db.json` 防泄露）；同源托管注入 `window.API_BASE="/api"` 前端自动走云端。

## 6. 移动端适配（已完成）
- **外壳三页**（index / train-standalone / admin）：输入框 16px（防 iOS 聚焦缩放）、主按钮全宽可点、操作规程iframe 手机上 height:64vh+min-height:380px 加高、布局收窄防溢出、记录台表格字号缩小。
- **6 台操作规程仿真页**（AAS-900T / L5S / MS105DU / QCS6000 / BSC-1300 / SPX-250B-Z）：统一注入 `@media(max-width:680px)+@media(max-width:420px)` 块，修复 `.dp`(3 列数据) 与 `.seq` 窄屏挤压、`.btn` 字号偏小、输入框 13px 触发 iOS 缩放、`.pb` 点击区小、`.hst` 数据条 gap 过大、`.sec` 大留白。注：这些页在 iframe 内（手机视口宽≈320–360px）命中 680 断点，移动样式对 iframe 内同样生效。

## 7. 边界与诚实说明
- 当前为**回退模式**：学员记录只留本机浏览器，换设备/换人互不可见；要「真多端共享」须把 `server/` 跑在自有云主机。
- CloudStudio 静态站**不能跑后端**；独立后端需用户自备云主机（README-部署.md 有步骤）。
- 微信扫码登录**已彻底移除**（纯前端静态站无法实现真 OAuth）。
