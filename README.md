# EnvLab · 环境监测与污染控制 交互实验演示

环境监测与污染控制方向的虚拟仿真实验，全部为**单文件网页**——打开即用，不装插件、不注册、不需要服务器。
与常见"把流程演一遍"的仿真不同，每一页都内置**判错机制**：

- **顺序红线**：步骤做错顺序会被拦住，并说明为什么这一步不能跳
- **参数变更即失效**：改了工况参数，之前已测的数据自动作废，必须重测
- **现场级告警**：出现异常数值时给出物理解释，而不是只弹一句"错误"
- **确定性模型**：用真实公式计算（传质单元数、Thomas 穿透曲线、分级效率、标干流量换算等），不用随机数凑结果

## 其中值得先看的几页

| 页面 | 看点 |
|---|---|
| 大气污染控制/旋风除尘器性能测定 | 顺序红线 + 漏风率对效率的影响（82% → 51%） |
| 大气污染控制/催化净化NOx（SCR） | 温度窗口与氨逃逸的权衡：多加氨换来的效率提升极小，逃逸却成倍上升 |
| 大气污染控制/活性炭吸附VOCs | Thomas 穿透曲线，什么时候该换炭 |
| 大气污染控制/烟气参数测定 | 同样的动压，温度越高流速越大、但标干流量越小 |
| 环境空气VOCs（罐采样） | 采样体积不足导致的"假阴性"陷阱 |
| 培训系统 | 学员记录、步骤得分、红线次数、训练证明 |

## 使用说明

- 页面为纯静态 HTML/CSS/JS，可直接下载整目录离线使用（适用于无外网的机房）。
- 支持移动端浏览与打印。
- 集内页面之间有交叉链接，**请保持目录结构不变**。

## 数据与免责

页面内的标准方法、限值与计算公式按现行国标与规范整理；演示用数据为构造数据，**仅用于教学，不作为检测结果依据**。
判错机制用于训练"知道什么是对的"，不能替代真实仪器的操作训练、现场监督与授权考核。
